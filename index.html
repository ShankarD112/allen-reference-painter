REFERENCE PAINTER GUIDE

Explore, compare, paint and save.

No matching topic. Try “cells”, “paint” or “export”.

Quick start
  1. Choose Start painting for a new workspace, or Upload saved work to resume a project.
  2. Load atlas regions in Regions, or choose source units and upload cell metadata in Cells. Try the synthetic example first if needed.
  3. Add optional gene counts, choose Color by, then explore cells with filters, the embedding plot and Locate.
  4. Save an editable project or a full scene ZIP before closing. There is no automatic save.
Regions and 3D navigation

Search by name, acronym or structure ID. The main-region dropdown narrows the alphabetical results. Load a region, select its row to make it active, and use visibility, color and opacity controls to compare surfaces. Load matching regions in bulk or cancel an ongoing bulk load. Large meshes can use substantial memory.

In Navigate mode, drag to orbit, scroll to zoom and right-drag to pan. Use 3D, Coronal, Sagittal or Dorsal for preset views, and Focus for the active region. Reference shell and slice-plane controls change the context around your regions.

Painting, layers and undo

Load and select a region, choose Paint or Erase, set the brush radius, then drag on its surface. Mirroring reflects selected faces across the atlas midline. Paint is a surface mask, not a volumetric segmentation.

Create separate paint layers, give them names and tags, and adjust their colors and visibility. Layer isolation, grow, shrink, invert and clear act on the current selection or layer as labeled. Deleting a layer or removing a region can discard paint, so save first.

Use Undo/Redo or Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z outside text fields. Escape returns to Navigate. Undo history holds up to 50 strokes; save projects to preserve masks between visits.

Data uploads, example cells and cell IDs

The paired Data cards accept CSV, TSV, delimited TXT and XLSX (first worksheet). Choose micrometres, millimetres or voxel indices before importing metadata. Coordinate columns can be x/y/z or AP/DV/ML; include a unique cell_id to match expression.

Counts files use genes in rows and cell IDs in column headers, with gene names in the first column. A blank top-left header from an R row-name export is accepted. Matching is case-sensitive after trimming surrounding spaces, never positional. Check the matching details for missing IDs. Duplicate IDs, duplicate genes and invalid values reject the new expression file.

The Showing badge identifies the displayed dataset. Uploading metadata while the synthetic example is active stages the file: click Load your uploaded data to use it, or keep the example. Load pending metadata before its gene counts. Replacing metadata clears the previous expression and cell settings.

Metadata files must be under 30 MB. Expression supports up to 5 million values, 100 MB for text or 15 MB for XLSX. Larger datasets should be subset before upload. Expression values are used as supplied, without normalization or log transformation.

write.csv(metadata_saved, "cells.csv", row.names = FALSE)
write.csv(counts_saved, "expression.csv", row.names = TRUE)
Color scales, shape, size and legends

Color by searches grouped Genes and Metadata options, each labeled continuous or categorical. Search, choose a variable and apply it; only one variable controls color at a time. Categories use discrete colors. Missing values are gray; zero expression is a measured value.

Continuous values support viridis, magma, plasma, red-blue, grayscale, the original scale, and custom two- or three-color scales. Minimum/maximum clipping changes display colors only. Empty bounds use the data range; Reset restores it. The legend scale includes hidden cells so filtering does not change its meaning.

Shape optionally uses categorical metadata; Size can use numeric or discrete metadata or a gene. Both default to None and have independent legends. Shape symbols repeat beyond five categories with a notice. These encodings apply to 3D, slices and the embedding plot.

Hover labels, Locate, slices and embedding

In Navigate mode, hover over a visible cell in 3D, either slice, or the embedding plot to see its cell_id, dataset, active color value and atlas coordinates. If no ID is available, the selected label or row number is used. Labels hide while dragging, on leaving a view, or with Escape. On touch devices, use the cell list and Locate.

Locate marks the cell in 3D and moves the coronal/sagittal slices to its coordinates. Slice sliders and exact indices explore depth; clicking a slice moves the crosshair. Hovering the slice also reports AP/DV/ML and atlas region information. Slice cells are shown within ±50 µm of the plane, not all loaded cells.

The optional embedding plot displays two numeric metadata columns, preferring UMAP1/UMAP2 when present. Choose its X/Y axes; click a point to Locate it. The app displays uploaded values—it does not calculate UMAP or t-SNE. Cells with missing axis values are not plotted.

Cell summaries, filters and visibility

Open Cell summary and choose a metadata field to see category counts, percentages of all loaded cells and visible counts. Click a category to isolate it, click again or Clear category isolation to restore it.

Add category filters and toggle values on/off. Add one or more gene filters, then drag the minimum/maximum sliders or enter exact bounds below each histogram. All category, summary and gene filters combine with AND. Missing expression fails a gene filter; the histograms show all measured metadata cells before filtering. Up to 50 gene filters are supported.

The visible/total count reports the result. Cell-list search finds rows by any metadata value; Show/Hide matching and row checkboxes set manual visibility. Clearing filters preserves cells you manually hid. The list shows the first 150 matches; refine the search to find a particular cell.

Save, export, resume and share
  • Editable project (.json): retains meshes, paint layers, cells, expression, encodings, filters and view settings for resuming work.
  • Full scene ZIP: includes meshes, analysis tables, cell/expression data and a resumable project. Cells-only scenes are supported.
  • Active ROI ZIP: exports the active region's painted faces and analysis data. It excludes cell/expression tables; paint an ROI first.
  • Interactive HTML: shares the current 3D scene offline with displayed colors, shapes, sizes and legends. It is a viewer, not the editable workspace; share JSON/ZIP too for editing or choosing other genes.
  • PNG figures: download the 3D view or slices as images.

Under Resume or combine work, choose Resume saved workspace to replace the current workspace, or Add files as separate paint layers to combine work. Projects validate atlas mesh identity and face IDs. With expression attached, duplicate cell IDs across combined tables are rejected; use Resume for the same dataset.

Coordinates, privacy and troubleshooting

The reference is Allen mouse 25 µm, BrainGlobe atlas version 3.1. Coordinates are AP/DV/ML micrometres from the BrainGlobe atlas origin, not bregma. Source voxel indices are converted at 25 µm. Outside-atlas coordinates are retained, so check units if cells appear displaced.

Data files are processed locally in your browser. Atlas assets are downloaded from the host. There is no account, automatic cloud save or cross-device synchronization. Downloaded projects and shared files contain the data included in those exports.

If a gene file does not match, compare the exact cell IDs and matrix orientation. Gray cells indicate missing values or unmatched IDs. If no cells appear, check visible/total counts, manual visibility, filters, embedding axes and slice depth. Retry atlas loading after a network error. Desktop browsers are recommended for large meshes.
