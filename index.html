REFERENCE PAINTER

A browser workspace for your atlas.

  1. Regions: search a name or acronym, then load a surface.
  2. Paint: choose a brush, paint a patch, and optionally mirror it.
  3. Cells: choose units, then import AP/DV/ML or x/y/z coordinates.
  4. Export: download analysis files or save an editable project.

Painting selects surface triangles; it does not create a volumetric segmentation. Face IDs refer to the exact packaged BrainGlobe 3.1 mesh. Coordinates use the atlas origin, not bregma.

All work stays in this browser unless you download and share it. Save your project before leaving.

Independent project; not an Allen Institute product. Atlas: Wang et al. (2020), Cell. Data and code notices.
